# ✍️ ブログ下書きジェネレーター

フォームにテーマを入れると、`claude -p` がブログ記事の下書き(Markdown)を書いてくれる最小構成のWebアプリです。

## 仕組み

```
ブラウザ(index.html)
   │  ① フォームの内容を POST /generate に送信
   ▼
Node.jsサーバー(server.js)
   │  ② コマンド実行: claude -p "プロンプト"
   ▼
Claude Code CLI
   │  ③ Markdownの下書きを標準出力に返す
   ▼
ブラウザがプレビュー表示
```

ポイントは **`claude -p` は「1回だけ実行して結果を返すコマンド」** ということ。
プログラムから普通のコマンドとして呼べるので、Webサーバーの部品にできます。

## 必要なもの

- Node.js 18以上(外部ライブラリは不要、`npm install` も不要)
- Claude Code CLI(`claude` コマンド)がインストール&ログイン済みであること
  - 確認方法: ターミナルで `claude -p "こんにちは"` と打って返事が来ればOK

## 使い方

```bash
cd blog-draft-generator
node server.js
```

ブラウザで http://localhost:3000 を開く → テーマを入力 → 「下書きを生成する」

## コードの読みどころ

- `server.js` の `askClaude()` 関数 — たった数行で `claude -p` を呼んでいます。ここがこのアプリの心臓部です。
- `buildPrompt()` 関数 — フォームの入力をプロンプト文に組み立てています。プロンプトを変えるだけで「メール文ジェネレーター」「SNS投稿ジェネレーター」などに改造できます。

## 次のステップ(発展課題)

1. **プロンプトの改造** — 「SEOキーワードを含める」「箇条書き多め」などの条件を追加してみる
2. **ファイル保存機能** — 生成した下書きを `drafts/` フォルダに自動保存する(`fs.writeFileSync` を1行足すだけ)
3. **Agent SDKへの移行** — `claude -p` の代わりに `@anthropic-ai/claude-agent-sdk` の `query()` を使うと、ストリーミング表示(文章が少しずつ出てくる)や会話の継続ができるようになります
4. **Web検索つき下書き** — `claude -p "...最新情報を検索して書いて"` のようにすると、ClaudeがWeb検索しながら書いてくれます(claude -p ならではの機能!)
