# 📓 メモ・日記の自動要約ダッシュボード

メモフォルダ(.md)をClaudeが読んで、「今週のまとめ」「やり残しリスト」「ハイライト」をブラウザに表示するアプリです。

## 前回(ブログ下書き)からのレベルアップポイント

|  | 前回 | 今回 |
|---|---|---|
| Claudeの役割 | プロンプトを読んで文章を書くだけ | **自分でファイルを探して読む** |
| コマンド | `claude -p "…"` | `claude -p "…" --allowedTools "Read,Glob" --add-dir <フォルダ>` |

`--allowedTools` でClaudeに「道具」の使用を許可するのが今回の核心です。
これにより、Claudeは指示を受けると **Readツールで実際にメモファイルを開いて読みます**。
プロンプトにファイルの中身を貼り付ける必要がありません。これがエージェントの第一歩です。

```
ブラウザ ──▶ server.js ──▶ claude -p + ツール許可
                              │
                              ├─ Read: 2026-06-08.md を読む
                              ├─ Read: 2026-06-10.md を読む
                              ├─ Read: 2026-06-12.md を読む
                              ▼
                          JSON形式でまとめを出力 ──▶ ダッシュボードに表示
```

## 使い方

```bash
cd memo-dashboard
node server.js                 # まずはサンプルメモで試す
node server.js ~/my-notes      # 慣れたら自分のメモフォルダを指定
```

ブラウザで http://localhost:3001 → 「今週を分析する」ボタンを押す(1分ほどかかります)。

直近7日以内に更新された `.md` ファイルが対象です。

## コードの読みどころ

- `askClaude()` の `--allowedTools "Read,Glob"` — 今回の主役。これを外すとClaudeはファイルを読めなくなります(試してみると違いがわかります)
- `buildPrompt()` — 「JSON形式だけを出力して」と指示している点。プログラムで結果を扱うときの定番テクニックです
- `parseResult()` — AIの出力は時々余計な文が混ざるので、JSON部分だけを取り出す保険をかけています

## 発展課題

1. **結果の保存** — 分析結果を `history/2026-06-12.json` のように保存して、過去の週と見比べられるようにする
2. **毎週自動実行** — `claude -p` はただのコマンドなので、cronやスケジューラで「毎週日曜の夜に自動分析」できる
3. **Writeツールも許可** — `--allowedTools "Read,Glob,Write"` にして「まとめを weekly-report.md として保存して」と頼むと、Claudeがファイル作成までやってくれる
4. **Agent SDK化** — `query()` を使うと「いまどのファイルを読んでいるか」をリアルタイムでブラウザに流せる(ストリーミング)
